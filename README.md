# Arman Barati — IT Infrastructure & Security Workfolio

Willkommen in meinem technischen Workfolio. Hier dokumentiere ich praktische Projekte aus meiner Ausbildung zum Fachinformatiker für Systemintegration und meiner Arbeit im IT-Umfeld am ZARM der Universität Bremen.

Mein Schwerpunkt liegt auf Linux-Systemadministration, Virtualisierung, Storage, Clustering, Netzwerken und Cybersecurity. Die Dokumentationen zeigen nicht nur das Ergebnis, sondern auch Planung, Umsetzung, Tests, Fehlerbilder und Lösungen.

## Ausgewählte Projekte

### [Proxmox & Rocky Linux Cluster](projects/proxmox-rocky-linux/README.md)

Aufbau eines Linux-Clusters mit einem Headnode und einem Compute Node auf Proxmox. Dokumentiert sind unter anderem Rocky Linux, getrennte Netzwerke, ZFS, NFS, Firewalld, SSH, Ganglia, Spack, OpenMPI und OpenFOAM.

[![Architektur des Proxmox-Clusters](assets/265cfa99fd310c5d.svg)](projects/proxmox-rocky-linux/README.md)

**Technologien:** Proxmox · Rocky Linux · ZFS · NFS · Firewalld · Ganglia · Spack · OpenMPI · OpenFOAM

### [Gentoo Linux auf Proxmox](projects/gentoo-linux/README.md)

Schrittweise Installation einer Gentoo-VM auf Proxmox, von Netzwerk und SSH über Partitionierung, XFS, Swap und Stage3-Verifikation bis zu Chroot, Portage, Kernel, Benutzerverwaltung und GRUB.

[![Gentoo-Installation auf Proxmox](assets/4b38fb7ae0975a3e.png)](projects/gentoo-linux/README.md)

**Technologien:** Proxmox · Gentoo Linux · OpenRC · SSH · XFS · Portage · GRUB
